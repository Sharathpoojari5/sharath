Made with

  • Map data © OpenStreetMap contributors, available under the Open Database Licence.
  • 3D engine three.js (MIT licence).
  • Music and sound effects: composed and synthesised in code for this game (chenda, dollu, tassa, nadaswaram, harmonium, tabla, jhanj, conch, gong and a formant vocalist). There are no samples, so there is nothing third-party to license.
  • Models, people, vehicles, stages and food: built procedurally in code. No downloaded assets.
  • Fonts on this site: Big Shoulders Display, Inter and Noto Sans Kannada from Google Fonts (SIL Open Font Licence).
  • Voices (optional): generated with open models such as AI4Bharat Indic Parler-TTS (Apache-2.0). Check each model's licence before you publish recordings.

Trailer

All footage is captured from the game. The trailer's music is the game's own soundtrack.

Language note

The Tulu lines are an unreviewed draft written without a native proofreader. If you speak Tulu and see something wrong, please tell us on the home page under "Report a bug".

Fan project

Namma Karkala is an independent fan-made game inspired by the Bengaluru game Benglooru. It shares no code, models, music or text with it. Every shop name, character and story is fictional; real place names are used only as map labels.
